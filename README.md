# Трекер привычек — Test Driven Development

Десктопное приложение C++17 / Qt Widgets для Windows 10: создание,
переименование и подтверждённое удаление привычек; неделя Пн–Вс;
отметки мышью и клавиатурой; текущие серии; статистика 7/30 дней;
встроенные цитаты; сохранение в PostgreSQL. Интерфейс на русском,
в пастельной розовой и бежевой палитре. Авторизация пользователя не нужна.

## Запуск

На основном сервере пока не подтверждены наличие TDD-баз и вход с паролем.
В локальном PowerShell из корня проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-database.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\run.ps1
```

Первую команду выполните один раз с административным входом PostgreSQL.
Вторая собирает приложение и запрашивает пароль роли приложения скрытым
вводом. Пароли не вводятся в чат, не сохраняются в файлах и не передаются
аргументами процессов. ExecutionPolicy меняется только для дочернего процесса.

Подробности: [настройка БД](docs/DATABASE_SETUP.md), [сборка и запуск](docs/RUN.md).
Приложение: `build/ascii/habit_tracker.exe`. Нужны найденные Qt/libpq;
скрипт задаёт пути к DLL. Автономный установщик не создавался.

## Проверки и TDD

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\check-all.ps1
```

Проходят **55 поведенческих тестов**: 22 проверки логики, 14 PostgreSQL,
19 Qt Widgets. Все три набора CTest проходят (каждый запускается отдельно).
Подтверждены сохранение между двумя отдельными процессами, контрольные
суммы статистики и интерфейсные сценарии при масштабе Qt 100/125/150%.

Для проверок автоматически запускается одноразовый PostgreSQL на свободном
порту 127.0.0.1 с базой `habit_tracker_tdd_test` и ролью без административных
прав. Случайный пароль существует только в памяти. После запуска сервер
останавливается, его каталог удаляется. Основной сервер localhost:5432
и базы SDD не используются. В ограниченной среде агента для запуска
PostgreSQL потребовалось выполнение вне песочницы.

Завершены TDD-циклы 1–39: новый тест → фактический RED → минимальная
реализация → GREEN накопленного набора. Дополнительные проверки, сразу
прошедшие на существующем коде, отдельно отмечены в журнале.

История Git начинается с общего снимка 208545f. Начиная с цикла 38,
RED и GREEN сохраняются отдельными коммитами вместе с протоколами.
Циклы 1–37 задним числом на коммиты не разбивались. Рабочая копия —
папка habit-tracker-tdd в «гитхаб-локальные репозитории» на рабочем столе.

## Стек и независимость версий

C++17; Qt 6.9.1 Core/Widgets/SQL/Test; QPSQL; MinGW 13.1.0 из Qt;
CMake 3.30.5; Ninja 1.12.1. PostgreSQL 18.6 подтверждён SQL-запросом
