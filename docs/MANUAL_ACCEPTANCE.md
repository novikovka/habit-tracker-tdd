# Ручная приёмка на постоянном сервере

Этот этап требует вашего локального ввода паролей. Агент их не получает.
Используется `habit_tracker_tdd_test` на localhost:5432, а не рабочая база.
Скрипт не очищает существующие данные и не меняет обычный профиль приложения.
Несекретный INI создаётся в исключённой из Git папке build/manual-acceptance-profile.

## Запуск

Для первой настройки выполните из локальной копии репозитория:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\manual-acceptance.ps1 -SetupDatabase
```

Если базы и роль уже созданы, не указывайте `-SetupDatabase`.
При настройке psql запросит пароль администратора PostgreSQL, затем дважды
новый пароль роли habit_tracker_tdd_app. Запомните пароль роли: run.ps1
запросит его перед каждым из двух запусков приложения. Ввод скрыт.
Повторный SetupDatabase заново задаёт пароль только роли TDD.

## Первый запуск приложения

1. Проверьте текущую неделю Пн–Вс, выделение сегодня и наличие цитаты.
2. Попробуйте добавить имя из пробелов: диалог должен остаться с ошибкой.
3. Создайте «Чтение» и «Прогулка». У «Чтение» отметьте сегодня и вчера
   (если вчера на другой неделе, перейдите назад). Вернитесь на текущую
   неделю: серия должна быть 2.
4. Переименуйте «Чтение» в «Чтение книги». Откройте другое переименование
   и отмените его. Откройте удаление и отмените его.
5. Проверьте недоступность будущих отметок. Закройте окно приложения.

## Второй запуск

Консоль повторно запросит тот же пароль роли TDD и сама откроет приложение.
Проверьте сохранение названия «Чтение книги», двух отметок и серии.
Если других отметок нет, статистика должна показывать 2 за 7 и за 30 дней,
а график — по одному выполнению сегодня и вчера. Начальная неделя снова текущая.
Проверьте переход Tab между действиями и отметку через Space/Enter.
Закройте окно после проверки.

## Что сообщить

Напишите, удалось ли подключиться, сохранились ли имя и отметки после
перезапуска, совпали ли серия и статистика. Если появилась ошибка, передайте
её текст без паролей. Сам запуск двух процессов ещё не считается ручной
приёмкой: результаты будут записаны в журнал только после вашего сообщения.
Обычный рабочий запуск без тестового профиля — scripts/run.ps1.
