### Ошибки процесса, не засчитанные как RED

1. Ошибка компиляции: QSqlDatabase::open ошибочно вызван с одним параметром.
   Исправлено на open(user, password) до первого поведенческого RED.
2. Windows initdb не принял --pwfile=- как stdin. Настройка изменена:
   bootstrap только на loopback, затем пароль через приватный stdin psql,
   включение SCRAM до тестов. Пароль в файл не записывался.
3. Песочница мешала созданию ограниченного Windows-токена PostgreSQL
   (ошибки 87/3). Изолированные тесты выполнены с разрешённым запуском
   вне песочницы; основной сервер не менялся.
4. При запуске pg_ctl из конвейера PowerShell ожидание зависало после
   готовности сервера. Сервер был штатно остановлен по конкретному каталогу.
   Первый вариант Start-Process неверно обработал ExitCode; временный
   экземпляр также остановлен. Исправление: ProcessStartInfo с CreateNoWindow
   и ожиданием самого pg_ctl через WaitForExit(timeout), без ожидания
   унаследованных потоков сервера. Успешные тесты штатно останавливают
   и удаляют свои кластеры. После итоговых прогонов postmaster.pid
   в build/pg-tests не найден, localhost:5432 продолжает отвечать.
5. Qt offscreen сообщал об отсутствующем каталоге шрифтов. Указан
   QT_QPA_FONTDIR=C:/Windows/Fonts только для тестового процесса.
   Остающийся QWARN propagateSizeHints относится к offscreen-плагину;
   тесты проходят. CMake предупреждает об отсутствии Vulkan headers,
   они не нужны используемым Qt Widgets/QPainter.
6. При обновлении документации apply_patch отклонял замену README через
   Delete+Add одной цели и несколько неточных контекстов. Файлы исправлены
   операцией Update; к поведению приложения эти ошибки не относятся.
